### 3. Git Commands Executed

```bash
# 1. Initialize local Git repository
git init

# 2. Rename default branch to main
git branch -M main

# 3. Add all governance and configuration files
git add .

# 4. Create initial commit using Conventional Commits standard
git commit -m "chore: initialize engineering portfolio platform"

# 5. Connect to public GitHub remote repository
git remote add origin https://github.com/balarajmp/portfolio-v2.git

# 6. Verify remote origin configuration
git remote -v

# 7. Push main branch to remote GitHub repository
git push -u origin main
```

### 5. Architectural Decisions Made
1. **Strict Conventional Commits:** Enforced commit prefix standard (`chore:`, `feat:`, `fix:`, `docs:`) to support automated CHANGELOG generation.
2. **Standardized Branching Model:** Established `main`, `feature/*`, `release/*`, and `hotfix/*` workflows documented in `CONTRIBUTING.md`.
3. **Cross-OS Compatibility:** Configured `.editorconfig` and `.gitattributes` to force LF line endings across Windows, Linux, and macOS environments.
