### 2. Design Decisions & System Architecture

1. **Obsidian Dark Depth Hierarchy:**
   - Global Canvas: `#09090b` (`--bg-canvas` / `bg-bg-canvas`)
   - Surface Tier 1 (Cards & Content Modules): `#121215` (`--bg-surface-1`)
   - Surface Tier 2 (Elevated Popovers & Active Items): `#1c1c21` (`--bg-surface-2`)
   - Surface Tier 3 (Modals & Toast Containers): `#27272a` (`--bg-surface-3`)
   - Surface Hover: `#1a1a22` (`--bg-surface-hover`)
   - Glass Backdrop: `rgba(9, 9, 11, 0.75)` with `12px` backdrop blur (`--bg-glass`).

2. **Electric Violet Accent Token:**
   - Single signature accent: Electric Violet 500 (`#8b5cf6`), paired with hover tint (`#a78bfa`), subtle callout fill (`rgba(139, 92, 246, 0.12)`), and backdrop glow (`rgba(139, 92, 246, 0.25)`).

3. **8pt / 4pt Spatial Rhythm Scale:**
   - Expressed via CSS custom properties (`--space-1` to `--space-24`) and mapped into Tailwind CSS (`spacing: { 1..24 }`), ensuring strict geometric alignment across viewports.

4. **Typography & Monospace Technical Scale:**
   - Sans font family: `Inter`, `Geist Sans`, `-apple-system`, `sans-serif`.
   - Technical mono family: `JetBrains Mono`, `Geist Mono`, `monospace`.
   - Responsive font size tokens covering `display` (48px/32px), `h1` (36px), `h2` (30px), `h3` (20px), `h4` (16px), `bodyLg` (18px), `bodyMd` (15px), `bodySm` (13px), `caption` (12px), `code` (13px), and `overline` (11px uppercase tag).

5. **Motion Physics & Easing Tokens:**
   - Micro interaction fast (`100ms`), normal (`150ms`), surface transition (`250ms`).
   - Custom spring physics curve: `cubic-bezier(0.16, 1, 0.3, 1)`.

6. **Z-Index Layering Order:**
   - Strict z-index scale: `base: 0`, `sticky: 100`, `dropdown: 200`, `drawer: 300`, `modal: 400`, `toast: 500`, `tooltip: 600`.

### 4. Accessibility Decisions (WCAG 2.1 AA Compliance)

1. **High Contrast Compliance:**
   - Primary text (`#f4f4f5`) on obsidian canvas (`#09090b`) yields a contrast ratio of **18.1:1** (exceeding WCAG AAA threshold of 7:1).
   - Secondary text (`#a1a1aa`) yields **8.2:1** contrast.

2. **Visible Focus Ring Standard:**
   - Global `:focus-visible` ring defined with `outline: 2px solid var(--border-focus); outline-offset: 2px;`.

3. **Motion Accessibility (`prefers-reduced-motion`):**
   - Implemented CSS media query override disabling all transition/animation durations (`0.01ms !important`) and setting `scroll-behavior: auto !important` for users requesting reduced motion.

### 5. Future Extensibility Architecture

- **Theme Engine Ready:** Built-in `[data-theme="light"]` token mapping structure allows seamless future light mode activation without changing component class names.
- **Zero Hardcoded Values:** Component implementation in subsequent milestones will consume tokens exclusively via Tailwind semantic utilities (e.g., `bg-bg-surface1`, `border-border-subtle`) or TypeScript token constants (`tokens.colors.accent.primary`).
